# Two-minute demo script

Record this after the Modal endpoint and a Grafana dashboard are actually running.
Do not record the local tiny-model page as if it were the fine-tuned Qwen model.

- 0:00–0:15 — One sentence: English question in, SQL out, and the execution-accuracy number from the README table.
- 0:15–0:50 — Demo UI: the same question to the base model, the fine-tuned model, and GPT-4o-mini. Show the SQL and the rows.
- 0:50–1:20 — Grafana while Locust is running.
- 1:20–1:40 — One Langfuse trace: backend, SQL, validation, tokens, cost.
- 1:40–2:00 — The results table and the cost conclusion, using only numbers that are in `results/final/`.
